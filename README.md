# ExpresCargot

ExpresCargot est un site vitrine fictif réalisé comme démonstration par MoreTIC.

Les services de livraison, les tarifs, les avis, les colis et les suivis présentés sur le site sont imaginaires. Aucun colis ne sera réellement pris en charge et aucune commande de livraison ne peut être passée.

Le QR code Revolut permet uniquement, de manière facultative, de soutenir la mascotte du projet. Avant tout paiement, vérifiez le destinataire affiché dans l’application Revolut.

ExpresCargot est indépendant de tout opérateur ferroviaire, service postal, entreprise de transport ou marque existante.

Le code et les visuels sont utilisés pour illustrer les possibilités d’un site vitrine : identité visuelle, contenu, interactions locales, formulaire simulé, responsive design et accessibilité.
